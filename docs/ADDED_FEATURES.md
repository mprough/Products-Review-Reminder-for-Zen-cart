# Added features

The modern Products Review Reminder release adds the following features to the original plugin:

- Self-contained Zen Cart Plugin Manager installation.
- Editable email subject, greeting, introduction, product question, review link text, and closing.
- Clearly listed email shortcodes for customer name, store name, and order number.
- Multiline custom text that creates suitable HTML and plain-text line breaks.
- HTML and plain-text reminder generation using Zen Cart's email system.
- Administrator preview using any real order without contacting the customer.
- Store-owner test email with selectable HTML or plain-text format.
- Safe opt-out routing test that cannot change customer data.
- Live customer-bound opt-out test sent only to the store owner.
- Customer opt-out status check and one-click test-record restoration.
- Signed one-click customer opt-out links that do not require login.
- Configurable trigger status, waiting period, lookback window, product limit, and batch limit.
- Default batch limit of 10 for shops processing large order volumes.
- Preservation of previous reminder history and customer opt-outs during upgrades.
- Runtime repair for missing Configuration and Tools menu registrations.
- Responsive, left-aligned HTML email layout with the configured Zen Cart email branding.
- Customer review page and opt-out page support across the declared Zen Cart versions.
- PHP lint testing across PHP 8.0 through 8.5.

Reminders remain manual. The administrator chooses the eligible orders and initiates each batch.
