# Security policy

Report security concerns privately through the [PRO-Webs helpdesk](https://prowebsinc.zohodesk.com/portal/en/newticket). Do not publish customer information, order information, credentials, tokens, or exploit details in a public GitHub issue.

This free plugin is provided without warranty.

Include the plugin version, Zen Cart version, PHP version, steps needed to reproduce the issue, and a sanitized error log. Remove customer names, email addresses, order details, database credentials, server paths, signed opt-out tokens, and other private data before submitting the report.
